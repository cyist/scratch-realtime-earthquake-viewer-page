它是怎么工作的

为什么不只打分：人对"这两个哪个更舒服"的判断远比"这个值几分"稳定；分数会随状态漂移。所以主要用相对比较，打分只偶尔用来校准。

感受板：按住手指，位置就是感受：左 = 有趣，右 = 普通，上 = 强烈，下 = 没感觉。目标是让你尽量久地待在左侧的斜线区。松手超过 1 秒算"需要休息"，输出暂停，休息时间不记录但计入总时长。

它怎么用这些数据：① 纵向闭环：偏强就慢慢减弱，进入顶部红区立即减弱，偏弱就加强。② 时间趋势：对每个波形拟合"随时间的变化"（越来越有趣 / 越来越普通 / 越来越难坚持 / 稳定），按 90 秒视野打分，而不是取平均。③ 新鲜度轮换：兴趣消退就换一个不同的，刚播过的会被暂时避开。④ 相邻微调：在区内稳定时小改一个维度，并把"不改会怎样"外推出来做对照，得到一次隐式的二选一。⑤ 防误判：自动估计你的反应延迟并据此对齐，波形过渡期、刚恢复、手指快速移动时的数据不用或降权。

平滑约定：波形都是 5–100 秒的循环（含其中的停顿）；切换用几秒的渐变；吮吸开关和旋转换向都有最短间隔，换向必须先经过 0。

自动续航播放：不用按着，按学到的新鲜期轮换你喜欢的几种波形，并按学到的耐受时长自动插入减弱期。

滑杆：25 维空间里每轮只沿一条线搜索——有时是一个有名字的维度（如"震动出场比例"），有时是模型算出的最有希望的方向。你边感受边拖，停下的位置同时胜过线的两端，一次操作给出多条信息。

模型：高斯过程偏好模型，把滑杆选择、二选一、打分、"想要更…"统一成一个效用函数（拉普拉斯近似），再用置信上界决定下一轮试哪里；旧反馈权重逐渐降低以适应感受变化。

参数：全局节奏、利落度、起落偏向、段落长度、段内渐强、段内加速、全体停顿；每个通道各有强度、起伏、快慢倍率、时间差、出场比例、出场时机。通道强度可以学到 0（几乎不用）。

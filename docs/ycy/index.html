吮吸档位：0 = 放气，1 = 保持，2 以上 = 吸气。"寸止"会让所有输出暂停指定时间后再柔和恢复，对任何玩法都有效。

设备内建模式 0 = 关闭

内建模式由设备固件自行运行，与速率控制二选一：某通道启用内建模式后，该通道的速率输出会置 0。
